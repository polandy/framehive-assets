# framehive-assets

Review screenshots for [Framehive](https://github.com/polandy/Framehive) pull requests.

A pull request that changes the UI shows the change as 2–3 small, cropped screenshots.
They live here, under `pr-<n>/`, and are linked from a comment on pull request `<n>`
(Framehive ADR 0017 and ADR 0019, procedure in `docs/pull-requests.md`).

These images are disposable. Nothing pins them, nothing in Framehive depends on them, and
this repository may be pruned or recreated at any time. A broken link in an old pull
request is accepted: the change itself is in the code and in the screenshot hashes.

Never put test data, release files or anything else here.
